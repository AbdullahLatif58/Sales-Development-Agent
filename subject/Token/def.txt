What is a Token?
     
     A token is the smallest meaningful unit of text that a tokenizer chooses to represent as one item.

token : I love Shopify.

Tokenizer : 
     
  Human
   │
   ▼
"I love Shopify"

["I"," love"," Shopify","."]


The tokenizer is the gateway to the model. Every single character you send must pass through it before the AI can “think.”

Transformer: 

             Think of the Transformer as a giant reasoning machine

             Create Shopify leads with emails

             The Transformer doesn’t read left to right like a normal program.

             Instead it builds relationships.

            Create
           /      \
          /        \
   Shopify ------ Leads
          \
           \
          Emails

          It figures out that:

* “Shopify” modifies “leads.”
* “emails” describes the leads.
* “Create” is the action.

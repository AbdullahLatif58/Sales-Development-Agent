KV Cache

When an LLM generates a response, it processes the context through its Transformer attention layers.


Query (Q)
Key   (K)
Value (V)


KV cache stores attention’s Key and Value representations from previous tokens so they don’t have to be recomputed during autoregressive decoding.

What is quantization?

Module 3 — Text Generation


 Context Window:   

                  A context window is the maximum number of tokens an LLM can “see” at one time.


                  If your model only supports 64k, you must decide what to trim:
- shorten the conversation history,
- retrieve fewer documents,
- compress older exchanges,
- reduce the requested output length.

This balancing act is one of the core engineering challenges in production AI systems.

---

# How major AI products handle this

- **ChatGPT:** Maintains conversation history and selectively trims or summarizes older messages when needed.
- **Claude:** Designed to work well with very long contexts, making it useful for long documents and codebases.
- **Gemini:** Also supports large contexts and is optimized for multimodal inputs (text, images, etc.).
- **Coding assistants (Cursor, Claude Code):** Don't send your whole repository. They index the project, retrieve relevant files, and include only the code needed for the current task.

---

# Why this matters for your AI SDR

Right now, your backend sends the full conversation history each time. That's a solid starting point and mirrors how many chat systems begin.

As conversations grow, you'll eventually need to evolve it:

1. Keep the most recent messages.
2. Summarize older sections.
3. Retrieve customer-specific information (RAG or memory).
4. Assemble an optimized prompt before each LLM call.

That's how long-running AI conversations remain fast, affordable, and coherent.
